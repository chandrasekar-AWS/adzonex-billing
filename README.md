# Ad ZoneX Billing
Installable web app (PWA) for estimates and bills. Runs on Android, iOS, Windows, macOS and Linux (phone, tablet, laptop, PC).

- **Billing**: client details, then an Excel-style table. Type a service, pick a suggestion, fill the row and the next row appears. "Digital services" switches to the digital table.
- **History**: every estimate and bill, with print, PDF and a print-ready history report.
- **Settings**: add/edit services, business and bank details, numbering, terms, logo, cloud sync and backup.
- An estimate becomes a bill when the first payment is recorded.

Backend (Supabase) setup is in the backend folder of the download: BACKEND-SETUP.md.
