# Build the real apps (Windows, Mac, Linux, Android)
1. Push this repo to GitHub.
2. Repo > **Actions** > **Build apps** > **Run workflow** (about 10 minutes).
3. Open the finished run and download from **Artifacts**:
   - `desktop-windows-latest`: Setup .exe
   - `desktop-macos-latest`: .dmg
   - `desktop-ubuntu-latest`: .AppImage and .deb
   - `android-apk`: app-debug.apk (allow "install unknown apps" on the phone)
iPhone/iPad: open the website link in Safari > Share > Add to Home Screen (an App Store app needs a paid Apple developer account).
